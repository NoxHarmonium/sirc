	{\Large\bfseries SIRC-1 Assembly Programmer's Manual}

	\vspace{1cm}

	\begin{minipage}{0.8\textwidth}
		This manual is the working guide to writing SIRC-1 assembly: the source language, every operand form and directive,
		how labels and constants are resolved, and how to assemble, link and run a program with the toolchain. It leaves the
		definition of each instruction to the companion SIRC-1 Architecture Reference Manual.

		\vspace{0.6cm}

		\textbf{Inside you will find:}
		\begin{itemize}
			\item The lexical rules and operand syntax of the language
			\item Condition codes, status update sources and shifts as they are written in source
			\item Directives, labels, constants and symbol references
			\item Step-by-step use of the assembler, linker and simulator
			\item The diagnostics the assembler produces and what the toolchain does not support
		\end{itemize}
	\end{minipage}
