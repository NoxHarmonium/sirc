\chapter{Electrical Characteristics}
\label{ch:electrical-characteristics}

The only electrical requirement currently specified is the supply: VCC1 and VCC2 must be connected to 5~V $\pm$ 5\% and
GND1 and GND2 to the 0~V rail (see Chapter~\ref{ch:signal-descriptions}).

The bus timing in this manual is cycle-level logical timing, measured in CLKI cycles. The following characteristics are
not yet specified and will be added to this chapter when they are:

\begin{itemize}
	\item Input and output voltage levels
	\item Clock frequency range
	\item Setup, hold and propagation delay times
	\item Fanout and maximum board loading
	\item Supply current and power dissipation
	\item Package dimensions and thermal characteristics
\end{itemize}

Until then, designs must not assume any value for these characteristics.
