\section{Opcode Patterns}

\subsection{Format Identification}

Bit numbers in this section refer to the 6-bit opcode value (instruction bits 31--26), not to the instruction word.

\begin{itemize}
	\item Opcode bits 5--4 = 00: Immediate format (\opcode{00}--\opcode{0F})
	\item Opcode bits 5--4 = 01: Memory and control operations (\opcode{10}--\opcode{1F}). Format is selected by opcode bit 0:
	      even opcodes use Immediate format, odd opcodes use Register format.
	\item Opcode bits 5--4 = 10: Short Immediate with Shift (\opcode{20}--\opcode{2F})
	\item Opcode bits 5--4 = 11: Register format (\opcode{30}--\opcode{3F})
\end{itemize}

\subsection{Save vs. Test}

\begin{itemize}
	\item Bit 3 = 0 and low nibble \texttt{0}--\texttt{6}: save result (\opcode{00}--\opcode{06}, \opcode{20}--\opcode{26},
	      \opcode{30}--\opcode{36})
	\item Bit 3 = 1 and low nibble \texttt{8}--\texttt{E}: test only, discard result (\opcode{08}--\opcode{0E},
	      \opcode{28}--\opcode{2E}, \opcode{38}--\opcode{3E})
	\item Low nibble \texttt{F} is the coprocessor call (\opcode{0F}, \opcode{3F}), not a test form
	\item Low nibble \texttt{7} is \mnemonic{LOAD} (\opcode{07}, \opcode{37})
	\item \opcode{27} and \opcode{2F} are undocumented
\end{itemize}

\subsection{Memory Operations Decoding}

For opcodes \opcode{10}--\opcode{1F}, bits encode memory operation type:

\begin{itemize}
	\item Bit 4 = 1: Always set for memory/control section
	\item Bits 3--2: Operation type
	      \begin{itemize}
		      \item 00 = Store
		      \item 01 = Load
		      \item 10 = Load Effective Address
		      \item 11 = Load EA with Link (jump to subroutine)
	      \end{itemize}
	\item Bit 1: Auto-update of the source address register (0 = no update, 1 = pre-decrement for STOR/LDEA, post-increment for
	      LOAD/LDEL). Only the low word of the pair is adjusted, and always by one word regardless of the displacement.
	\item Bit 0: Immediate (0) or Register (1) offset
\end{itemize}

\section{Undocumented Instructions}

The following opcodes are undocumented and should not be used in production code:

\begin{itemize}
	\item \opcode{08}, \opcode{09}, \opcode{0B}, \opcode{0D} (Immediate format, test variants)
	\item \opcode{28}, \opcode{29}, \opcode{2B}, \opcode{2D} (Short Immediate format, test variants)
	\item \opcode{38}, \opcode{39}, \opcode{3B}, \opcode{3D} (Register format, test variants)
	\item \opcode{27}, \opcode{2F} (no public assembly syntax)
\end{itemize}

The twelve test-variant opcodes above execute in hardware, but their behavior is architecturally undefined and may
change between CPU revisions. See Appendix~\ref{appendix:undocumented} for details on all fourteen undocumented
opcodes, including \opcode{27} and \opcode{2F}.
