	{\Large\bfseries SIRC-1 CPU Reference Manual}

	\vspace{1cm}

	\begin{minipage}{0.8\textwidth}
		The SIRC-1 brings together a clean 16-bit load/store architecture, a fully specified six-stage execution
		model, and an extensible coprocessor interface, without sacrificing the predictability system programmers
		and hardware designers depend on. This manual documents every instruction, register, exception, and bus
		signal to an implementation-ready level of detail, so that assemblers, compilers, operating systems, and
		hardware implementations can all be built directly from its pages, without consulting any other source.

		\vspace{0.6cm}

		\textbf{Inside you will find:}
		\begin{itemize}
			\item The complete SIRCIS instruction set reference, arranged for quick lookup by mnemonic
			\item Full exception, interrupt, and reset specifications
			\item Bus timing diagrams for hardware and peripheral designers
			\item Coprocessor and future-model compatibility guidelines
		\end{itemize}
	\end{minipage}
